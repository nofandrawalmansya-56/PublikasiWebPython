Modul 1: Dasar Python & Variabel

Sintaksis dasar, mencetak output, serta menyimpan informasi ke variabel.

Python adalah bahasa pemrograman yang sangat ramah pemula karena sintaksnya yang menyerupai bahasa Inggris. Di modul ini, Anda mempelajari cara menampilkan teks ke layar dengan fungsi print() dan menyimpan nilai dalam variabel.

contoh_dasar.py Tipe Data: String, Int, Float 
# 1. Mencetak Pesan
print("Selamat Datang di PyAcademy!")

# 2. Variabel dan Tipe Data
nama = "Budi"           # String
umur = 20               # Integer
tinggi = 175.5          # Float
is_active = True        # Boolean

# 3. Format String (f-string)
print(f"Halo {nama}, umur kamu {umur} tahun.")
Tips Penting: Python bersifat Case-Sensitive (membedakan huruf besar dan kecil). Variabel Nama dan nama dianggap variabel berbeda.

Modul 2: Kontrol Alur (If-Else & Loop)

Percabangan logika keputusan dan perulangan otomatis.

Kontrol alur memungkinkan program mengambil keputusan berdasarkan kondisi tertentu (if / elif / else) dan mengulangi perintah berulang kali (for / while).

percabangan_loop.py
# Percabangan Logika
nilai = 85

if nilai >= 90:
    print("Grade: A")
elif nilai >= 75:
    print("Grade: B")
else:
    print("Grade: C")

# Loop dengan range()
print("Hitung Mundur:")
for i in range(3, 0, -1):
    print(f"Detik ke-{i}")

Modul 3: Struktur Data Python

Mengelola sekumpulan data dengan List, Tuple, Dictionary, dan Set.

Python memiliki 4 struktur data bawaan utama: List (berurutan dan bisa diubah), Tuple (tidak dapat diubah), Dictionary (pasangan Key-Value), dan Set (kumpulan elemen unik).

struktur_data.py
# List (Daftar belanja)
buah = ["Apel", "Pisang", "Jeruk"]
buah.append("Mangga")

# Dictionary (Data Mahasiswa)
mhs = {
    "nama": "Siti",
    "jurusan": "Informatika",
    "ipk": 3.92
}

print(f"Buah favorit: {buah[0]}")
print(f"IPK {mhs['nama']}: {mhs['ipk']}")

Modul 4: Fungsi & Reusabilitas Kode

Membuat fungsi kustom dengan blok `def`, parameter, dan return value.

Fungsi membantu Anda menghindari pengulangan kode (DRY - Don't Repeat Yourself). Fungsi didefinisikan menggunakan kata kunci def.

fungsi.py
def hitung_diskon(harga, persen=10):
    total = harga - (harga * (persen / 100))
    return total

# Pemanggilan Fungsi
harga_awal = 100000
harga_akhir = hitung_diskon(harga_awal, 20)
print(f"Harga setelah diskon: Rp {int(harga_akhir)}")

Modul 5: Pemrograman OOP (Class & Object)

Pemrograman Berorientasi Objek untuk skala aplikasi besar.

Object-Oriented Programming (OOP) memodelkan objek dunia nyata menjadi cetak biru (Class) yang memiliki atribut (Property) dan perilaku (Method).

oop_dasar.py
class Mobil:
    def __init__(self, merk, warna):
        self.merk = merk
        self.warna = warna

    def klakson(self):
        print(f"Mobil {self.merk} berwarna {self.warna}: Beep Beep! 🚗")

# Instansiasi Objek
mobil_budi = Mobil("Tesla", "Merah")
mobil_budi.klakson()

Modul 6: Exception Handling & File I/O

Penanganan error (Try-Except) dan manipulasi berkas file.

Agar program tidak hancur (crash) saat terjadi kesalahan kalkulasi, gunakan blok try - except untuk menangani error secara elegan.

handling_error.py
try:
    pembilang = 10
    penyebut = 0
    hasil = pembilang / penyebut
    print(hasil)
except ZeroDivisionError:
    print("Error: Angka tidak bisa dibagi dengan nol!")
finally:
    print("Selesai mengeksekusi penanganan error.")
