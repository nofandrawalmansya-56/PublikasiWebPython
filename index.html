Panduan penggunaan

Apakah PyAcademy gratis?

Halaman pembelajaran ini dapat digunakan gratis. Runtime Python di browser membutuhkan internet untuk memuat Pyodide pertama kali.

Apakah editor ini menjalankan Python sungguhan?

Ya. Editor menggunakan Pyodide, distribusi Python yang berjalan di browser melalui WebAssembly. Tidak semua paket Python atau fitur sistem operasi tersedia.

Bagaimana urutan belajar yang disarankan?

Ikuti modul dari nomor 1 secara berurutan. Baca penjelasan, jalankan contoh, ubah kode, lalu selesaikan tantangan sebelum lanjut.

Apakah progres belajar tersimpan?

Versi ini belum memiliki akun atau sinkronisasi progres antardevice. Tandai modul yang sudah dipelajari secara pribadi; fitur penyimpanan dapat ditambahkan pada pengembangan berikutnya.
